# Discord: start here message

Pin the text below the line in the development channel. Keep it in sync with CONTRIBUTING.md.

---

**Want to help? Start here.**

**1. See what is open.** Everything that needs doing is one list:
<https://github.com/wololo-wololo/VIcky-Blue/issues/12>
Blockers are at the top of each milestone. `good first issue` marks the easy ways in.

**2. Claim before you start.** Open the issue you want and comment `/claim`. You become its
assignee, the list shows it as taken, and this channel gets a message. If someone else already
holds it, the bot tells you: offer to help on that issue, or pick another one.

**3. Work on the issue's branch** and open a draft pull request early so people can see where
you are heading. Details: <https://github.com/wololo-wololo/VIcky-Blue/blob/main/CONTRIBUTING.md#joining-in>

**4. Stopping? Comment `/unclaim`** so someone else can pick it up. Claims with no activity for
two weeks may be released by a maintainer.

**5. Found a new problem?** Open an issue for it first, then claim it. That way it shows up
here and nobody investigates the same thing twice.

**Rules, here and on GitHub:** never name the target title or its series, and never share game
files, dumps or links to them. Call it "the target title". You need your own legal copy to
test.

A claim only counts on GitHub. Saying "I will take it" in chat reserves nothing.
